# EWA Poultry & Farming Android app

This is an Android Studio project wrapping the EWA mobile-friendly business site in a lightweight Android WebView app.

## Build an APK
1. Install Android Studio on a computer.
2. Open this `EWA_Poultry_Android_Project` folder in Android Studio.
3. Allow Gradle sync and install the Android SDK Platform 35 if prompted.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location (normally `app/build/outputs/apk/debug/app-debug.apk`).

## App details
- App name: EWA Poultry & Farming
- Application ID: `com.ewapoultry.app`
- Version: 1.0
- Product prices are intentionally not displayed; customers are directed to WhatsApp for current prices.
- Business location and contact details are those supplied by the business owner.

A signed release build and Play Store publication require the owner's developer account and signing credentials. This source package is not itself an APK.
